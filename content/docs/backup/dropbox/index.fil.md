Ang Dropbox ay isang cloud storage service kung saan maaari mong itago ang mga backup file sa sarili mong Dropbox space, kaya ikaw ang may ganap na kontrol sa iyong data.

Mas madali ring maibalik ang iyong data mula sa cloud backup kapag nawala, nasira, o nanakaw ang device mo, o kapag lumipat ka sa bagong device. Mag-sign in lang sa Dropbox mula sa app at i-restore ang backup.

# Paano mag-sign in

Bago magsimula, tiyaking mayroon kang Dropbox account. Kung wala ka pa, magparehistro sa [dropbox.com](https://www.dropbox.com/). Pagkatapos, buksan ang backup screen ng app, piliin ang **Dropbox**, at mag-sign in upang pahintulutan ang app. Kapag naaprubahan na ang access, ise-save ng app ang iyong mga backup sa nakalaang espasyo nito sa Dropbox, karaniwang nasa `Apps/Lite Writer` o katulad na path na para sa app. Hindi maa-access ng app ang iba mo pang file sa Dropbox.
