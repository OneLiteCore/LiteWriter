Dropbox est un service de stockage cloud qui vous permet de conserver vos sauvegardes dans votre propre espace Dropbox. Vous gardez ainsi le contrôle total de vos données.

Une sauvegarde dans le cloud facilite également la récupération de vos données si votre appareil est perdu, endommagé ou volé, ou lorsque vous passez à un nouvel appareil. Il vous suffit de vous connecter à Dropbox depuis l'application et de restaurer votre sauvegarde.

# Comment se connecter

Avant de commencer, assurez-vous d'avoir un compte Dropbox. Si vous n'en avez pas encore, créez-en un sur [dropbox.com](https://www.dropbox.com/). Ouvrez ensuite l'écran de sauvegarde de l'application, sélectionnez **Dropbox**, puis connectez-vous pour autoriser l'application. Une fois l'accès autorisé, l'application enregistre vos sauvegardes dans un espace qui lui est réservé au sein de votre stockage Dropbox, généralement sous `Apps/Lite Writer` ou dans un chemin similaire propre à l'application. Elle n'accède à aucun de vos autres fichiers Dropbox.
