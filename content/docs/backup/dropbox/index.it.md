Dropbox è un servizio di archiviazione cloud che ti permette di conservare i backup nel tuo spazio Dropbox personale, mantenendo così il pieno controllo dei tuoi dati.

Il backup sul cloud rende anche molto più semplice recuperare i dati se il dispositivo viene smarrito, danneggiato o rubato, oppure quando passi a un nuovo dispositivo. Ti basta accedere a Dropbox dall'app e ripristinare il backup.

# Come accedere

Prima di iniziare, assicurati di avere un account Dropbox. Se non ne hai ancora uno, registrati su [dropbox.com](https://www.dropbox.com/). Poi apri la schermata di backup dell'app, seleziona **Dropbox** e accedi per autorizzare l'app. Dopo l'autorizzazione, l'app salverà i backup in uno spazio dedicato all'interno del tuo Dropbox, di solito nel percorso `Apps/Lite Writer` o in un percorso simile specifico dell'app. L'app non accede agli altri file presenti nel tuo Dropbox.
