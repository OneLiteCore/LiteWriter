title: Layanan cadangan Dropbox
---

Dropbox adalah layanan penyimpanan cloud yang memungkinkan Anda menyimpan file cadangan di ruang Dropbox milik Anda sendiri. Dengan begitu, Anda memegang kendali penuh atas data Anda.

Cadangan cloud juga memudahkan pemulihan data jika perangkat Anda hilang, rusak, atau dicuri, maupun saat Anda beralih ke perangkat baru. Cukup masuk ke Dropbox dari aplikasi, lalu pulihkan data dari cadangan.

# Cara masuk

Sebelum memulai, pastikan Anda memiliki akun Dropbox. Jika belum, daftarkan akun di [dropbox.com](https://www.dropbox.com/). Setelah itu, buka layar cadangan di aplikasi, pilih **Dropbox**, lalu masuk untuk memberikan izin akses kepada aplikasi. Setelah diizinkan, aplikasi akan menyimpan cadangan di ruang khusus aplikasi dalam penyimpanan Dropbox Anda, biasanya di `Apps/Lite Writer` atau path khusus aplikasi yang serupa. Aplikasi tidak mengakses file Dropbox Anda yang lain.
