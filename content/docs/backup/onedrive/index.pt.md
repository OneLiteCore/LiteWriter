title: Serviço de backup do OneDrive
---

O OneDrive é um serviço de armazenamento em nuvem da Microsoft. Seus dados de backup são armazenados no seu próprio drive na nuvem, para que você mantenha o controle total sobre seus dados.

Como este é um serviço de backup em nuvem, ele também ajuda quando algo inesperado acontece. Se o dispositivo for perdido, danificado ou os dados locais forem removidos, você ainda poderá restaurar seus dados a partir do backup armazenado no OneDrive.

# Como entrar

Abra a página de configurações do aplicativo, mude para a guia **OneDrive** e toque em Entrar. Após o login, o aplicativo cria uma pasta no caminho **/Apps/Lite Writer** no seu OneDrive e armazena os dados de backup nela.
