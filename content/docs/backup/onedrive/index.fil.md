title: Serbisyo ng backup ng OneDrive
---

Ang OneDrive ay isang serbisyo ng cloud storage mula sa Microsoft. Ang iyong backup data ay naka-store sa sarili mong cloud drive, kaya ganap mong kontrolado ang iyong data.

Dahil ito ay isang cloud backup service, makakatulong din ito kapag may nangyaring hindi inaasahan. Kung mawala o masira ang device mo, o matanggal ang lokal na data, maaari mo pa ring i-restore ang iyong data mula sa backup na naka-store sa OneDrive.

# Paano mag-sign in

Buksan ang settings page ng app, lumipat sa tab na **OneDrive**, at i-tap ang Sign in. Pagkatapos mag-sign in, gagawa ang app ng folder sa path na **/Apps/Lite Writer** sa iyong OneDrive at doon iimbak ang backup data.
