title: Service de sauvegarde OneDrive
---

OneDrive est un service de stockage cloud fourni par Microsoft. Vos données de sauvegarde sont stockées sur votre propre lecteur cloud, ce qui vous permet de garder le contrôle total de vos données.

Comme il s'agit d'un service de sauvegarde cloud, il peut aussi aider en cas d'imprévu. Si votre appareil est perdu, endommagé ou si des données locales sont supprimées, vous pouvez toujours restaurer vos données à partir de la sauvegarde stockée dans OneDrive.

# Comment se connecter

Ouvrez la page des paramètres de l'application, basculez vers l'onglet **OneDrive**, puis appuyez sur Se connecter. Après la connexion, l'application crée un dossier au chemin **/Apps/Lite Writer** dans votre OneDrive et y stocke les données de sauvegarde.
