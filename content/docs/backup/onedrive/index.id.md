title: Layanan cadangan OneDrive
---

OneDrive adalah layanan penyimpanan cloud yang disediakan Microsoft. Data cadangan Anda disimpan di drive cloud milik Anda sendiri, sehingga Anda tetap menguasai data Anda sepenuhnya.

Karena ini adalah layanan cadangan cloud, layanan ini juga membantu saat terjadi hal tak terduga. Jika perangkat Anda hilang, rusak, atau data lokal dihapus, Anda tetap dapat memulihkan data dari cadangan yang disimpan di OneDrive.

# Cara masuk

Buka halaman pengaturan aplikasi, beralih ke tab **OneDrive**, lalu ketuk Masuk. Setelah masuk, aplikasi membuat folder di jalur **/Apps/Lite Writer** di OneDrive Anda dan menyimpan data cadangan di sana.
