Samba เป็นโปรโตคอลแชร์ไฟล์แบบทั่วไปสำหรับเครือข่ายท้องถิ่น (LAN) และทำงานร่วมกับอุปกรณ์และระบบที่หลากหลายได้เป็นอย่างดี

# ทำความเข้าใจพารามิเตอร์การเข้าสู่ระบบ

- **ชื่อโฮสต์หรือที่อยู่ IP**: ที่อยู่ของอุปกรณ์ที่รันเซิร์ฟเวอร์ Samba
- **พอร์ต**: พอร์ตของเซิร์ฟเวอร์ Samba ค่าเริ่มต้นคือ **445**
- **ชื่อแชร์ Samba**: เซิร์ฟเวอร์ Samba หนึ่งเครื่องสามารถตั้งค่าแชร์ได้หลายรายการ คุณจึงต้องระบุว่าจะใช้แชร์ใด
- **เส้นทางโฟลเดอร์จัดเก็บ**: เส้นทางจัดเก็บภายในแชร์ จะเว้นว่างไว้ก็ได้ ไฟล์สำรองจะถูกเก็บในเส้นทางนี้ หากว่างไว้จะใช้ไดเรกทอรีรากของแชร์
- **ชื่อผู้ใช้**: ชื่อผู้ใช้ ซึ่งต้องไม่ว่าง
- **รหัสผ่าน**: รหัสผ่าน ซึ่งต้องไม่ว่าง
- **SSID WiFi แบบจำกัด**: จำกัดการสำรองข้อมูลให้ใช้เฉพาะ WiFi เครือข่ายใดเครือข่ายหนึ่ง เว้นว่างไว้เพื่อให้สำรองข้อมูลบน WiFi ใดก็ได้ หรือระบุ SSID เพื่อให้สำรองเฉพาะเมื่อเชื่อมต่อกับเครือข่ายนั้น เนื่องจาก Samba ใช้แชร์ไฟล์ผ่านเครือข่ายท้องถิ่น ตัวเลือกนี้จึงช่วยให้สำรองข้อมูลอยู่บน WiFi ที่เชื่อถือได้
