Samba 是一种通用的局域网文件共享协议，对各类设备和系统都有着良好的兼容性。

# 登录参数说明

- **主机名或 IP 地址**：运行 Samba 服务端的设备的地址。
- **端口**：Samba 服务端的端口，默认为 **445**。
- **Samba 共享名**：一个 Samba 服务端可以配置多个共享，你需要指定要使用哪一个。
- **存储文件夹路径**：共享下的存储路径，可为空。备份文件将存储在此路径下；留空则使用共享配置的根目录。
- **用户名**：用户名，不可为空。
- **密码**：密码，不可为空。
- **限定 WiFi SSID**：将备份限定在指定的 WiFi 网络下执行。留空表示不限制 WiFi，填写 SSID 后则仅在连接该 WiFi 时才执行备份——因为 Samba 本身就是用于在局域网内共享文件的。
