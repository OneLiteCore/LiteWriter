Samba — это универсальный протокол обмена файлами для локальных сетей (LAN), который хорошо работает с самыми разными устройствами и системами.

# Понимание параметров входа

- **Имя хоста или IP-адрес**: адрес устройства, на котором работает сервер Samba.
- **Порт**: порт сервера Samba. По умолчанию — **445**.
- **Имя общего ресурса Samba**: сервер Samba может иметь несколько настроек общих ресурсов, поэтому нужно указать, какой именно использовать.
- **Путь к папке хранения**: путь хранения внутри общего ресурса. Может быть пустым. Резервные копии сохраняются по этому пути; если он пуст, используется корневой каталог ресурса.
- **Имя пользователя**: имя пользователя, не может быть пустым.
- **Пароль**: пароль, не может быть пустым.
- **Ограниченный SSID Wi-Fi**: ограничивает резервное копирование определённой сетью Wi-Fi. Оставьте поле пустым, чтобы разрешить копирование в любой сети, или укажите SSID, чтобы оно выполнялось только в этой сети. Samba используется для обмена файлами в локальной сети, поэтому так ваши резервные копии остаются в доверенной сети.
