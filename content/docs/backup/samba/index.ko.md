Samba는 로컬 네트워크(LAN)에서 쓰는 범용 파일 공유 프로토콜로, 다양한 기기와 시스템에서 잘 동작합니다.

# 로그인 매개변수 이해

- **호스트 이름 또는 IP 주소**: Samba 서버를 실행하는 기기의 주소입니다.
- **포트**: Samba 서버의 포트입니다. 기본값은 **445**입니다.
- **Samba 공유 이름**: Samba 서버 하나에 여러 공유 설정이 있을 수 있으므로, 사용할 공유를 지정해야 합니다.
- **저장 폴더 경로**: 공유 내부의 저장 경로입니다. 비워 둘 수 있습니다. 백업 파일은 이 경로 아래에 저장되며, 비어 있으면 공유의 루트 디렉터리가 사용됩니다.
- **사용자 이름**: 사용자 이름으로, 비워 둘 수 없습니다.
- **비밀번호**: 비밀번호로, 비워 둘 수 없습니다.
- **제한된 WiFi SSID**: 백업을 특정 WiFi 네트워크로 한정합니다. 아무 WiFi에서나 백업하려면 비워 두고, 해당 네트워크에서만 백업하려면 SSID를 입력하세요. Samba는 로컬 네트워크에서 파일을 공유하는 용도이므로, 이 옵션은 백업을 신뢰할 수 있는 WiFi에서만 실행되도록 합니다.
