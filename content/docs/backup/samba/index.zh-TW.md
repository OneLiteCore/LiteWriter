Samba 是一種通用的區域網路檔案共享協定，對各類裝置和系統都有良好的相容性。

# 登入參數說明

- **主機名稱或 IP 位址**：執行 Samba 伺服端的裝置的位址。
- **連接埠**：Samba 伺服端的連接埠，預設為 **445**。
- **Samba 共用名稱**：一個 Samba 伺服端可以設定多個共用，你需要指定要使用哪一個。
- **儲存資料夾路徑**：共用下的儲存路徑，可為空。備份檔案將儲存在此路徑下；留空則使用共用設定的根目錄。
- **使用者名稱**：使用者名稱，不可為空。
- **密碼**：密碼，不可為空。
- **限定 WiFi SSID**：將備份限定在指定的 WiFi 網路下執行。留空表示不限制 WiFi，填寫 SSID 後則僅在連線到該 WiFi 時才執行備份——因為 Samba 本身就是用於在區域網路內共用檔案的。
