Samba — це універсальний протокол обміну файлами для локальних мереж (LAN), який добре працює з найрізноманітнішими пристроями та системами.

# Розуміння параметрів входу

- **Ім'я хоста або IP-адреса**: адреса пристрою, на якому працює сервер Samba.
- **Порт**: порт сервера Samba. За замовчуванням — **445**.
- **Ім'я спільного ресурсу Samba**: сервер Samba може мати кілька конфігурацій спільних ресурсів, тож потрібно вказати, який саме використовувати.
- **Шлях до папки зберігання**: шлях зберігання всередині спільного ресурсу. Може бути порожнім. Резервні копії зберігатимуться за цим шляхом; якщо він порожній, використовується кореневий каталог ресурсу.
- **Ім'я користувача**: ім'я користувача, яке не може бути порожнім.
- **Пароль**: пароль, який не може бути порожнім.
- **Обмежений SSID Wi-Fi**: обмежує резервне копіювання певною мережею Wi-Fi. Залиште поле порожнім, щоб дозволити копіювання в будь-якій мережі, або вкажіть SSID, щоб воно виконувалося лише в цій мережі. Оскільки Samba використовується для обміну файлами в локальній мережі, це тримає ваші резервні копії на довіреній мережі.
