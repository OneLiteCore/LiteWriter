title: Samba バックアップサービス
---

Samba は、ローカルエリアネットワーク（LAN）で使われる汎用的なファイル共有プロトコルで、さまざまなデバイスやシステムと良好に連携します。

# ログインパラメータの説明

- **ホスト名または IP アドレス**: Samba サーバーを実行しているデバイスのアドレス。
- **ポート**: Samba サーバーのポート。デフォルトは **445** です。
- **Samba 共有名**: 1 つの Samba サーバーには複数の共有設定を持たせられるため、使用する共有を指定する必要があります。
- **保存フォルダのパス**: 共有内の保存パス。空にできます。バックアップファイルはこのパスに保存され、空の場合は共有のルートディレクトリが使われます。
- **ユーザー名**: ユーザー名。空にすることはできません。
- **パスワード**: パスワード。空にすることはできません。
- **制限付き WiFi SSID**: バックアップを特定の WiFi ネットワークに限定します。任意の WiFi でバックアップできるようにするには空のままにし、そのネットワークでのみ実行するには SSID を入力します。Samba はローカルネットワークでのファイル共有に使われるため、この設定によりバックアップを信頼できる WiFi 上に留められます。
