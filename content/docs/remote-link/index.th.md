ฟีเจอร์ "ลิงก์" ช่วยให้คุณแมปข้อมูลของแอปเป็นไดเรกทอรีบน PC เพื่อให้คุณใช้ซอฟต์แวร์บน PC ในการแก้ไขและจัดการข้อมูลของคุณได้

ฟีเจอร์นี้อิงตามโปรโตคอล **WebDav** ทั่วไป ระบบปฏิบัติการส่วนใหญ่ควรจะรองรับได้ทันที แต่อาจใช้งานไม่ง่ายนัก นี่จึงเป็นวิธีที่ง่ายกว่า

## Windows

บนแพลตฟอร์ม Windows เราขอแนะนำซอฟต์แวร์ของบุคคลที่สาม **RaiDrive** คุณสามารถดาวน์โหลดได้โดยคลิกลิงก์ด้านล่าง:

[RaiDrive 1.8.0 https://raidrive.en.uptodown.com/windows/download/2114805](https://raidrive.en.uptodown.com/windows/download/2114805)

(เวอร์ชัน 1.8.0 ไม่ใช่เวอร์ชันล่าสุด แต่มีทุกอย่างที่เราต้องการ และที่สำคัญกว่านั้นคือไม่มีโฆษณา)

ติดตั้งและเปิดโปรแกรม คุณอาจเห็นแผงแบบนี้ เพียงทำตามคำแนะนำ:

![RaiDrive setup](/img/add_drive.webp)

1. คลิกปุ่ม "Add" ด้านบนเพื่อเข้าสู่การกำหนดค่า
2. ไปที่แท็บ "NAS" แล้วเลือกตัวเลือก WebDav
3. ป้อนชื่อไดรฟ์ตามที่คุณต้องการ
4. ป้อนที่อยู่
    - ข้างข้อความ "address" คุณอาจเห็นช่องทำเครื่องหมาย ให้ปล่อยให้เป็น **ไม่เลือก** ไว้ เพื่อให้เราใช้ url แบบ http ได้
    - ป้อนที่อยู่ IP และหมายเลขพอร์ต ซึ่งคุณสามารถหาได้เมื่อเปิดฟีเจอร์ลิงก์ในแอป
5. ป้อนชื่อผู้ใช้และรหัสผ่านที่คุณกำหนดเอง หากมี มิฉะนั้นให้ทำเครื่องหมายช่อง "Anonymous"
6. คลิกปุ่ม "OK" เพื่อเริ่มการแมป

## Linux หรือ MacOS

### MacOS

บน macOS คุณสามารถใช้ **Finder** ในตัวเพื่อเชื่อมต่อกับบริการ WebDav ได้:

1. เปิด **Finder**
2. ในแถบเมนู คลิก **Go** แล้วเลือก **Connect to Server…** (หรือกด `Command + K`)
3. ป้อนที่อยู่ที่แสดงในแอปลงในช่องที่อยู่ เช่น `http://192.168.1.100:8080`
4. คลิก **Connect**
5. หากมีการแจ้งให้ป้อน ให้ป้อนชื่อผู้ใช้และรหัสผ่าน หรือเชื่อมต่อในฐานะผู้เยี่ยมชม
6. เมื่อเชื่อมต่อแล้ว บริการ WebDav จะปรากฏใน Finder เป็นไดรฟ์เครือข่าย และคุณสามารถเข้าถึงและจัดการข้อมูลได้เหมือนโฟลเดอร์ในเครื่อง

### Linux

บน Linux (ใช้เดสก์ท็อป Ubuntu เป็นตัวอย่าง) คุณสามารถใช้ตัวจัดการไฟล์ในตัวเพื่อเชื่อมต่อได้:

1. เปิดแอป **Files**
2. คลิก **Other Locations** ในแถบด้านข้างซ้าย
3. หาช่อง **Connect to Server** ที่ด้านล่าง
4. ป้อนที่อยู่ในรูปแบบ `dav://IP:พอร์ต` เช่น `dav://192.168.1.100:8080`
5. คลิก **Connect**
6. หากมีการแจ้งให้ป้อน ให้ป้อนชื่อผู้ใช้และรหัสผ่าน หรือเชื่อมต่อแบบไม่ระบุชื่อ
7. เมื่อเชื่อมต่อแล้ว บริการ WebDav จะปรากฏในตัวจัดการไฟล์เป็นตำแหน่งเครือข่าย
